## Dataset

This project uses the **Mall Customer Segmentation Dataset** from Kaggle.

**Original dataset:** https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python

The dataset is not included in this repository. To run the notebook, download `Mall_Customers.csv` from the original Kaggle source and place it in the same folder as `Customer_Segmentation.ipynb`.

Please refer to the original dataset page for its applicable license and usage terms.
