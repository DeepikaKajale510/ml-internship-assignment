# Machine Learning Internship Assignments

This repository contains my weekly assignments, practice exercises, and machine learning projects completed during my Machine Learning internship. It covers data preprocessing, exploratory data analysis, supervised learning, unsupervised learning, model evaluation, and customer segmentation using Python and Scikit-learn.

## Weekly Progress

### Week 1: Data Analysis and Preprocessing
- Exploratory Data Analysis (EDA)
- Handling missing data
- Encoding categorical variables
- Titanic dataset cleaning and preprocessing
- House price prediction using Linear Regression

### Week 2: Supervised Machine Learning
- Linear Regression
- Logistic Regression
- Model evaluation and accuracy comparison
- House Price Prediction mini-project
- Titanic classification using Logistic Regression, Decision Tree, and K-Nearest Neighbors (KNN)
- Hyperparameter tuning

### Week 3: Unsupervised Machine Learning
- K-Means clustering
- Principal Component Analysis (PCA)
- Iris dataset clustering
- Cluster visualization and interpretation
- Dimensionality reduction and explained variance

### Week 4: Model Evaluation and Customer Segmentation
- Cross-validation using `cross_val_score`
- Hyperparameter tuning using `GridSearchCV`
- Saving and loading trained models using `joblib`
- Support Vector Machine (SVM) classification
- Customer Segmentation using K-Means clustering
- Elbow Method and Silhouette Score
- Customer segment visualization and interpretation

## Technologies and Tools

- **Language:** Python

- **Tools:** Jupyter Notebook, Git, GitHub
